This repository presents RAKG, an agentic graph-guided API knowledge retrieval framework that takes a natural-language programming query as input and outputs a ranked list of <API, KU> pairs to help developers find relevant API knowledge. RAKG operates in three phases. Phase I (API Knowledge Collection) collects <API, DP>, <API, SG>, and <API, QA> pairs from SP, API TU, and SO, respectively. Phase II (API Knowledge Graph Modeling) models the collected API knowledge by constructing a two-layer API knowledge graph. The API layer contains API nodes, whereas the knowledge layer contains KU nodes. API--API relations connect API nodes within the API layer, KU--KU relations connect KU nodes within the knowledge layer, and API--KU relations connect each API with its associated KUs across the two layers. Phase III (API Knowledge Retrieval) first parses the query to obtain initial <API, KU> candidates, then performs adaptive API knowledge investigation through the knowledge deepening and knowledge broadening strategies, with the option to stop when the collected evidence is sufficient. Finally, RAKG scores the retained candidates according to API match and KU support, and returns a ranked list of <API, KU> pairs.
